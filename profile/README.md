# ROAS Expert

Agentic SEO and growth marketing agency. We build free, open tools that show whether search engines, AI assistants and AI shopping agents can crawl, read and buy from a website.

## Free tools

| Tool | What it answers |
|---|---|
| [AI SEO audit](https://tools.roasexpert.com/) | Can Google and ChatGPT read my site? Score out of 100 with fixes for my CMS. |
| [Product page check](https://tools.roasexpert.com/product) | Can AI shopping assistants read my price, stock, shipping and returns? |
| [Agent readiness check](https://tools.roasexpert.com/agent-check) | Can an AI agent find, read and buy from my store? |
| [Compare with competitors](https://tools.roasexpert.com/compare) | Which checks does a competitor pass that I fail? |
| [AI visibility check](https://tools.roasexpert.com/visibility) | How often do ChatGPT, Perplexity and Claude name my brand? |
| [AI bot log analyzer](https://tools.roasexpert.com/bot-log) | Which AI crawlers visit my site and what gets blocked? |
| [llms.txt generator](https://tools.roasexpert.com/llms-txt) | An llms.txt built from my homepage and sitemap. |
| [robots.txt builder for AI crawlers](https://tools.roasexpert.com/robots-ai) | Which AI bots does my robots.txt allow? |
| [MER and break-even ROAS calculator](https://tools.roasexpert.com/mer-calculator) | What ROAS do I need to make money? |
| [CAC payback calculator](https://tools.roasexpert.com/cac-payback) | How many months until a customer pays back, with churn? |
